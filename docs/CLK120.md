# CLK120 — Invisible format characters in shipped URLs

Creator and brand teams copy tracking links out of Google Docs, Slack, Word, and PDFs. Those tools silently insert format characters that do not show in most spreadsheets:

- U+200B zero-width space
- U+00AD soft hyphen
- U+FEFF byte order mark
- U+00A0 / U+202F non-breaking spaces
- U+200C / U+200D / U+2060 joiners

The link looks valid. Browsers and GA4 parse a different host or UTM value. Attribution then lands in `(direct) / (none)` or a polluted dimension.

## Rule

- Code: `CLK120`
- Severity: error
- Scan the raw URL string before `urlsplit`
- Keep CLK120 when the same URL also fails CLK001 (BOM prefix, soft-hyphen hosts)
- Do not flag ordinary ASCII spaces (CLK113 / CLK001)

## What this is not

- CLK113: visible leading/trailing or whitespace-only UTM values
- CLK117: HTML entities such as `&amp;`
- CLK118: UTM pairs left in the fragment
- CLK119: percent-encoded `&` separators (`%26utm_`)

## Privacy

Offline string inspection. No network. No extra dependencies.
