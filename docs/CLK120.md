# CLK120 — invisible copy/paste characters

## Problem

Campaign URLs copied from Google Docs, Slack, Word, and PDFs often contain
format characters that do not render in spreadsheets:

| Character | Name |
| --- | --- |
| U+200B | zero-width space |
| U+00AD | soft hyphen |
| U+FEFF | BOM / zero-width no-break space |
| U+00A0 | non-breaking space |
| U+202F | narrow no-break space |
| U+200C | zero-width non-joiner |
| U+200D | zero-width joiner |
| U+2060 | word joiner |

Browsers and GA4 treat the resulting host or UTM value as different from the
visible text. Attribution then lands in `(direct)` / `(none)` or a polluted
dimension.

## Rule

- Code: `CLK120`
- Severity: error
- Scan the raw URL string before parsing
- Keep CLK120 even if the URL also fails `CLK001`
- Do not flag ordinary ASCII spaces (`CLK113` / `CLK001`)

## Scope

Offline, deterministic, no network, no extra dependencies. Synthetic
fixtures only in tests.
