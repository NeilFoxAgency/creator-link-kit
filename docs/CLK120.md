# CLK120 — platform redirect wrappers

Creators and coordinators often paste a YouTube, Facebook, Instagram, or
Google *wrapper* instead of the brand landing page:

- `https://www.youtube.com/redirect?q=https%3A%2F%2Fshop.example.com%2F...`
- `https://l.facebook.com/l.php?u=...`
- `https://l.instagram.com/?u=...`
- `https://www.google.com/url?q=...`
- `https://href.li/?https://shop.example.com/...`

Analytics then records the wrapper host. UTM values on the inner URL never
reach GA4 as first-party query parameters on the brand domain.

`creator_link_kit.redirects.redirect_wrapper_message` detects these offline.
It does not fetch the nested URL.

Wire it into `validate_url` with:

```python
from .redirects import redirect_wrapper_message

wrapper_message = redirect_wrapper_message(parsed, url)
if wrapper_message is not None:
    issues.append(Issue("CLK120", "error", wrapper_message, url=url))
```

Insert that block after the existing CLK118 fragment check.
