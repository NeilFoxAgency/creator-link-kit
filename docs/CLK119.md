# CLK119: percent-encoded UTM separators

Shipped creator links often arrive from Excel, Slack, or CMS exports with `&` encoded as `%26`:

```
https://shop.example.com/product?utm_source=youtube%26utm_medium=influencer&utm_campaign=cmp-spring-launch
```

`urllib.parse.parse_qsl` and GA4 split only on a raw `&`. The later UTM pair stays inside the earlier value, so medium/campaign attribution is silently lost.

## Rule

- Code: `CLK119`
- Severity: error
- Detect:
  - raw query contains `%26utm_` (case-insensitive)
  - or a decoded query value matches `(?:[?&]|%26)utm_(source|medium|campaign|term|content|id)=`
- Do not match a normal `?utm_source=` / `&utm_medium=` query string.
- Distinct from CLK117 (HTML entities) and CLK118 (fragment UTMs).

## Usage

`clk audit` and `validate_url` surface CLK119 after the package is imported. Synthetic example URLs only; no live campaign data is required.
