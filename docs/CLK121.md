# CLK121 — Invisible or format-control characters

## Problem

Operators paste tracked URLs from Slack, Notion, Google Docs, Word, and email.
Those tools often inject characters that do not show up on screen:

- zero-width space (U+200B)
- BOM / ZWNBSP (U+FEFF)
- non-breaking space (U+00A0)
- soft hyphen (U+00AD)
- wrapped newlines and other C0 controls

GA4 stores the hidden code point as part of the dimension. Allowlists fail and
visually identical sources split into two rows.

## Rule

`validate_url` scans the raw URL before parsing. Invisible or format-control
characters emit **CLK121** (error). The URL is not rewritten.

Visible leading/trailing spaces remain **CLK113**.

## Operator fix

Delete the hidden character and rebuild the link with `clk build`.
