# CLK121 — Invisible or format-control characters

## Problem

Creator and brand operators paste tracked URLs from Slack, Notion, Google Docs,
Word, and email. Those tools often inject characters that do not show up in the
address bar or a spreadsheet cell:

- zero-width space (U+200B)
- BOM / ZWNBSP (U+FEFF)
- non-breaking space (U+00A0)
- soft hyphen (U+00AD)
- wrapped newlines and other C0 controls

GA4 and similar tools store the hidden code point as part of the dimension.
Allowlists fail, two visually identical sources split into two rows, and
sessions look untagged even though the link appeared correct.

## Rule

`validate_url` scans the **raw** URL before parsing. If any format-control,
invisible, or line-wrapping control character is present, it emits **CLK121**
(error).

Ordinary visible spaces inside a value remain **CLK113** after query parsing.
This rule does not rewrite the URL.

## Operator fix

Delete the hidden character and rebuild the link with `clk build`, or paste the
URL into a plain-text editor that can show invisibles and remove them.
