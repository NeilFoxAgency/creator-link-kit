# CLK131 — control characters in UTM values

Spreadsheet paste, multi-line CMS cells, and exported Excel columns often put
`LF`, `CR`, `TAB`, `NUL`, or `DEL` inside a UTM value. Analytics tools treat
those as distinct dimensions, and CSV or QR export can split the row.

`clk build`, `clk batch`, and `clk audit` now emit **CLK131** when a governed
UTM value contains any ASCII C0 control character or DEL. Ordinary spaces are
not flagged (those remain CLK113 only when they lead or trail the value).

Example: `utm_campaign=cmp-%0Aspring` is an error. `utm_campaign=cmp spring`
is not CLK131.
